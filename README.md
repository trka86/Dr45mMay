# Академия May — лендинг обучения по Last Asylum: Plague

Сайт: https://trka86.github.io/Dr45mMay/

## Что здесь лежит

| Файл | Зачем |
|---|---|
| `index.html` | сама страница (все тексты — внутри него) |
| `hero.jpg`, `may.jpg`, `may-back.jpg`, `hotline.jpg` | иллюстрации (`may-back.jpg` — оборотная сторона портрета) |
| `og-image.jpg` | картинка-превью для ссылок в Telegram / VK (2400×1260) |
| `favicon.svg`, `favicon.ico`, `apple-touch-icon.png` | иконка сайта во вкладке и на рабочем столе телефона |

## Как поменять текст

Открой `index.html` на GitHub → карандаш («Edit this file») → поправь → зелёная кнопка **Commit changes**.
Через минуту изменения появятся на сайте.

Куда смотреть:
- заголовок и подзаголовок первого экрана — блок `<!-- HERO -->`
- три ступени — блок `<!-- TIERS -->`
- наставник и строчка про донаты — блок `<!-- MENTOR -->`
- горячая линия и контакты (VK / Telegram) — блок `<!-- HOTLINE -->`
- вопросы-ответы — блок `<!-- FAQ -->`

## Если сайт переехал на другой адрес

В `index.html` найди `https://trka86.github.io/Dr45mMay` (встречается несколько раз в `<head>`) и замени на новый адрес —
иначе Telegram и VK не найдут картинку-превью.

## Пересобрать из исходников

Исходники (шаблон, оригиналы картинок, сборщик) лежат в папке `landing/` рядом с этой:
`python3 landing/build.py https://новый-адрес` — соберёт и автономный `index.html`, и эту папку заново.
